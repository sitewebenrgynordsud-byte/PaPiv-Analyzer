# **App Name**: PaPiv Analyzer

## Core Features:

- Document Upload: Allow users to upload documents for analysis, taking URLs to documents as well.
- AI-Powered Insights: Utilize a tool that scans uploaded papers and provide an executive summary.
- Key Sentence Highlighting: Highlight important sentences for each document.
- Sentiment Analysis: Provide sentiment analysis of the document (positive, negative, neutral).
- Custom Analysis Options: Allow users to customize their analysis with filters like date published, sources etc.
- Download Analysis Report: Generate an analysis report from LLM which the user can download, summarizing key findings and sentiment.

## Style Guidelines:

- Primary color: Midnight blue (#2c3e50) for a professional, intellectual feel.
- Background color: Light gray (#f0f2f5) for a clean, modern interface.
- Accent color: Soft green (#3498db) to indicate key findings and user actions.
- Body text font: 'Inter', a grotesque-style sans-serif, offering a machined, neutral and modern look; use it for main body text.
- Headline Font: 'Space Grotesk', a proportional sans-serif, creates a tech-centered feel and is well-suited to headlines. 
- Use 'lucide-react' icons consistently, emphasizing clarity and immediate recognizability.
- Maintain a clean, structured layout with intuitive navigation for ease of use.
- Subtle animations and transitions should guide the user without being distracting, and to signal that key analyses are actively processing in the background.
